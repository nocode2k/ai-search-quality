## 성공 기준

- 핵심 질의에 대한 사람 검토 일치율이 기준선보다 악화되지 않습니다.
- 진단 결과가 스키마 검증을 통과합니다.
- 역할별 실패가 전체 진단 실패로 전파되지 않습니다.
- P95/P99 처리시간, 비용, 실패율이 기록됩니다.
- 자동 적용 없이 승인 가능한 액션 후보가 생성됩니다.
