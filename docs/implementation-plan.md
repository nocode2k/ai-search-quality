## 사람 검토 원칙

- reason code가 맞더라도 자동으로 검색 정책을 변경하지 않습니다.
- `EXACT_MATCH_DEMOTED`, `POPULARITY_OVERBOOST`, `NEGATIVE_CONSTRAINT_VIOLATION`은 우선 검토합니다.
- evidence가 실제 검색 결과·Explain/Profile 로그로 재현되지 않으면 반려합니다.
- 운영 적용 전 별도 오프라인 골든셋과 A/B 테스트로 CTR, CVR, 무결과율을 확인합니다.

## 성공 기준

- 핵심 질의에 대한 사람 검토 일치율이 기준선보다 악화되지 않습니다.
- 진단 결과가 스키마 검증을 통과합니다.
- 역할별 실패가 전체 진단 실패로 전파되지 않습니다.
- P95/P99 처리시간, 비용, 실패율이 기록됩니다.
- 자동 적용 없이 승인 가능한 액션 후보가 생성됩니다.
